# 무명회 테니스 클럽 — Netlify 공유 버전

여러 사람이 각자 폰으로 접속해도 **투표·경기결과·입상 내역 등이 모두 같은 데이터**로 보이는 버전입니다.
(데이터는 Netlify Blobs에 저장되고, 화면은 20초마다 + 앱을 다시 열 때 자동으로 최신 상태가 됩니다.)

## 폴더 구성
```
public/                  ← 실제 사이트 (index.html, manifest.json, sw.js, icons/)
netlify/functions/state.mjs  ← 공유 데이터 저장 API (/api/state)
netlify.toml, package.json   ← Netlify 설정
```

## 배포 방법 (1번을 추천)

### 1) GitHub 연결 (가장 쉬움)
1. GitHub에서 새 저장소(repository)를 만들고, 이 폴더의 **모든 파일**을 그대로 올립니다.
2. Netlify → **Add new site → Import an existing project** → 방금 만든 저장소 선택.
3. 설정은 건드릴 필요 없이 **Deploy** (빌드 명령은 비워 둬도 됩니다. `netlify.toml`에 이미 들어 있습니다).
4. 배포가 끝나면 나오는 주소(`https://○○○.netlify.app`)를 회원들에게 공유합니다.

### 2) 컴퓨터에서 명령어로 배포
```
npm install
npx netlify-cli login
npx netlify-cli deploy --prod --build
```
처음에 사이트를 새로 만들지 연결할지 물어보면 새로 만들기를 선택하세요.

> 폴더를 끌어다 놓는 "Netlify Drop" 방식은 함수(`netlify/functions`)가 제대로 빌드되지 않을 수 있어 권장하지 않습니다.

## 처음 한 번만 — 기존 데이터 옮기기
기존 앱(claude.ai 에서 쓰던 버전)에 입력해 둔 데이터가 있다면:
1. **기존 앱**에서 운영자로 로그인 → 홈 탭 맨 아래 **백업 / 복원 → 내보내기** → 칸에 생긴 글을 전체 복사.
2. **새 Netlify 주소**를 열고(처음 열면 기본 회원 명단으로 시작합니다) 운영자로 로그인.
   - 윤준식 님은 전화번호가 비어 있어서 처음 한 번 "운영자 초기 설정" 화면에서 번호를 정해야 합니다.
3. 홈 탭 맨 아래 **백업 / 복원** 칸에 붙여넣고 **가져오기**.
   → 서버의 데이터가 그 내용으로 교체되고, 이후 모든 회원이 같은 데이터를 봅니다.
   (교체 직전의 서버 데이터는 자동으로 서버 백업에 보관됩니다.)

옮길 데이터가 없다면 이 단계는 건너뛰어도 됩니다.

## 알아두면 좋은 점
- **운영자 기능 제한은 화면(앱) 안에서만 걸려 있습니다.** 주소를 아는 사람이 일부러 서버를 직접 호출하면 막을 수 없어요.
  클럽 회원끼리 쓰는 용도에는 충분하지만, 주소는 회원에게만 공유하세요.
- 로그인 비밀번호(전화번호 뒤 4자리 등)도 이제 서버에 같이 저장되어 **어느 기기에서든 같은 비밀번호**로 접속됩니다.
- 서버에는 **하루 1번 자동 백업**(최근 30개)이 쌓입니다.
  - 목록: `https://내주소/api/state?backups`
  - 내용: `https://내주소/api/state?backup=2026-10-21` → 나온 글을 복사해서 앱의 **백업 / 복원 → 가져오기**에 붙여넣으면 그 날로 복원됩니다.
- 이 기기에만 있는 **백업 / 복원 목록**은 이전과 같이 동작합니다 (기기 안 보관).
- 인터넷이 잠깐 끊겨도 입력은 기기에 남아 있다가, 연결되면 자동으로 서버에 올라갑니다. 화면 맨 아래에 "● 모두와 공유 중"이 보이면 정상입니다.
- 동시에 여러 명이 입력해도 **서로 다른 칸**(각자의 투표, 서로 다른 경기 기록 등)은 모두 보존됩니다.
  같은 칸을 동시에 고치면 마지막에 저장한 쪽이 남습니다.
- 사용량: 접속 중인 화면이 20초마다 서버를 한 번 확인합니다. 인원이 많으면 Netlify 무료 한도를 확인해 보세요.

## GitHub 수동 백업
운영자가 홈 탭의 "지금 백업"을 누르면 현재 데이터가 이 저장소의 `backups` 브랜치(`backups/backup-날짜_시간.json`)에 저장됩니다.
- Netlify → Site configuration → Environment variables 에 `GITHUB_TOKEN`(이 저장소 Contents: Read and write 권한의 fine-grained 토큰)을 추가해야 동작합니다.
- 전화번호 가운데 4자리는 `0000`으로 바꾸고, 비밀번호·사진은 제외합니다.

## 주간 자동 백업
매주 월요일 00:00(한국시간)에 운영자 접속과 상관없이 서버가 자동 백업합니다 (`netlify/functions/weekly-backup.mjs`).
- Netlify 저장소에 `weekly-날짜` 스냅샷 (최근 26주 보관)
- `GITHUB_TOKEN`이 있으면 GitHub `backups` 브랜치에도 저장
